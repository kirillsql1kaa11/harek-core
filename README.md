# Harek Core

Центральное графическое микроядро и интерактивная платформа рабочего пространства (доски) для запуска модулей, виджетов и системных расширений Harek.

Ядро реализует архитектуру Pure Microkernel: сама по себе программа представляет собой минимальную хост-оболочку с шиной событий и реестром сервисов, а любая визуальная или функциональная часть дополняется и модифицируется подключаемыми плагинами.

## Ключевые возможности

- Интерактивный рабочий холст (Board Canvas) с координатной сеткой и свободным перемещением виджетов.
- Механизм Drag-and-Drop: перетаскивание архива плагина (.harekplugin, .zip) прямо на доску для мгновенной распаковки, валидации и монтирования.
- Динамическая загрузка двух классов модулей:
  - Прикладные виджеты (board-widget): интерактивные карточки с независимым жизненным циклом и поддержкой изменения размеров.
  - Системные расширения ядра (core-extension): модули глубокой интеграции, способные модифицировать стили, слоты UI и сервисы ядра на этапе загрузки.
- Встроенная шина событий (Event Bus) для организации слабосвязанного взаимодействия между виджетами и ядром.
- Реестр сервисов ядра (Service Registry) с поддержкой подмены и переопределения реализаций.
- Конвейер хуков (Hooks Pipeline) для аудита жизненного цикла модулей.
- Живой инспектор ядра (Kernel Inspector) с просмотром логов в реальном времени, активных сервисов, хуков и телеметрии шины событий.
- Встроенный каталог демонстрационных модулей для тестирования и отладки.

## Системные требования

- Node.js 20.0.0 или новее
- npm 10.0.0 или новее
- Современный веб-браузер с поддержкой ES2022 и CSS Backdrop Filter

## Быстрый старт

### 1. Установка зависимостей

```powershell
npm install
```

### 2. Запуск в режиме разработки

```powershell
npm run dev
```

После запуска приложение доступно по адресу `http://localhost:3000`.

### 3. Сборка для публикации

```powershell
npm run build
```
