# Harek Core

Центральное графическое микроядро и интерактивная десктопная платформа рабочего пространства (доски) для запуска модулей, виджетов и системных расширений Harek.

Ядро реализует архитектуру Pure Microkernel: программа представляет собой минимальную хост-оболочку с шиной событий и реестром сервисов, а вся функциональность дополняется и модифицируется подключаемыми плагинами.

## Способы запуска приложения

### 1. Запуск десктопного приложения (.exe)

В корневой папке проекта собран исполняемый файл **`HarekCore.exe`**.

Запустить его можно двумя способами:
- Двойным кликом по файлу `HarekCore.exe` в Проводнике Windows.
- Через терминал:
  ```powershell
  npm start
  ```

Приложение запускается в нативном графическом окне Windows с аппаратным ускорением на базе встроенного компонента Microsoft Edge WebView2 и поддержкой Drag-and-Drop.

### 2. Запуск в режиме разработки (Dev Server)

```powershell
npm run dev
```

Интерфейс доступен в браузере по адресу `http://localhost:3000`.

### 3. Пересборка веб-части и .exe лаунчера

```powershell
npm run build:exe
```

## Ключевые возможности

- Интерактивный рабочий холст (Board Canvas) с координатной сеткой и свободным перемещением виджетов.
- Механизм Drag-and-Drop: перетаскивание архива плагина (.harekplugin, .zip) прямо на доску для мгновенной распаковки, валидации и монтирования.
- Динамическая загрузка двух классов модулей:
  - Прикладные виджеты (board-widget): интерактивные карточки с независимым жизненным циклом и поддержкой изменения размеров.
  - Системные расширения ядра (core-extension): модули глубокой интеграции, способные модифицировать стили, слоты UI и сервисы ядра на этапе загрузки.
- Встроенная шина событий (Event Bus) для организации слабосвязанного взаимодействия между виджетами и ядром.
- Реестр сервисов ядра (Service Registry) с поддержкой подмены и переопределения реализаций.
- Конвейер хуков (Hooks Pipeline) для аудита жизненного цикла модулей.
- Живой инспектор ядра (Kernel Inspector) с просмотром логов в реальном времени, активных сервисов, хуков и телеметрии шины событий.
- Встроенный каталог демонстрационных модулей для тестирования и отладки.

## Системные требования

- Windows 10 (версия 1809+) или Windows 11
- Microsoft Edge WebView2 Runtime (предустановлен в Windows 10/11)
- .NET 10.0 SDK / Runtime (для пересборки лаунчера из исходников)
- Node.js 20.0.0 или новее

## Структура проекта

```text
├── HarekCore.exe         # Скомпилированный нативный десктопный исполняемый файл
├── launcher/             # Исходный код нативного лаунчера на C# / WebView2
│   ├── MainWindow.cs
│   ├── Program.cs
│   └── launcher.csproj
├── src/                  # Исходный код микроядра и веб-интерфейса
│   ├── kernel/           # Микроядро, шина событий, реестры сервисов и менеджер плагинов
│   ├── board/            # Интерактивный холст доски и контейнеры виджетов
│   ├── ui/               # Панель инструментов и модальные окна
│   ├── sample-plugins/   # Встроенные эталонные плагины для демонстрации
│   ├── styles/           # Таблицы стилей оформления
│   └── main.ts           # Точка входа и инициализация ядра
├── dist/                 # Скомпилированный продакшен-бандл веб-интерфейса
├── package.json          # Зависимости и команды сборки
├── LICENSE               # Лицензия MIT
└── README.md             # Документация проекта
```
